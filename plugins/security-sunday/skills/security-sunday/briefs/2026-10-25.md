# Security Sunday brief — 2026-10-25

First brief; covers Aug–Oct 2026 (plus older items we are still exposed to). Researched
2026-10-25. Versions marked ✓ were checked against npm, GitHub releases/advisories, Docker Hub,
the Ubuntu USN API or the hosts themselves the same day; the rest are as the linked sources state.

## Do this week (most urgent first)

1. **Next.js → 16.4.x (≥16.4.1), or 15.5.28 for rogapy.** Two unauthenticated RCEs (Oct 14);
   **no 16.2.x or 16.3.x fix exists**, so every Next 16 project needs the 16.4 minor. Pasapy
   and jajotopa run Next on glibc Linux on our VPS, the setup the SVG/image RCE targets.
2. **Better Auth → ≥1.7.7 (take 1.7.12)** where it is 1.7.6: pasapy, shared_landings
   (yetapatours too if it is ever revived). Critical: OAuth state usable as a magic link to sign
   in as another user. Our sign-in is magic links.
3. **PgBouncer 1.25.2 → 1.26.1** on the VPS (`edoburu/pgbouncer:v1.26.1-p0` ✓ exists). SCRAM auth
   bypass between users, and the pooled port 6543 is public. Needs the user's OK (a restart drops
   pooled connections for every project).
4. **Traefik 3.6.25 is out of support (since Aug 16) with critical/high advisories fixed only in
   3.7.x** ✓. Dokploy v0.30.10 (latest release) still pins 3.6.25; Dokploy's canary defaults to
   3.7.16 ✓ (`TRAEFIK_VERSION`). Plan with the user: wait for the next Dokploy release or set
   `TRAEFIK_VERSION=3.7.16`; read the 3.7 migration notes first; re-check the `tailnet-only`
   middleware afterwards.
5. **React 19.2.x → 19.2.9, 19.3.0 → 19.3.1** (RSC RCE, critical). Next bundles its own copy
   (fixed by item 1); TanStack Start / any `react-server-dom-*` user needs the React bump.
6. **Electron → 44.9.x** (kururu 44.3.0, platypost 44.5.1): eMudhra CA distrust plus Sep/Aug
   highs. Needs a new app build to reach users.
7. **pnpm pins below 10.34.5 / 11.11.0** (install-time path traversal / file write): platypost
   `pnpm@10.28.0`, subignite `pnpm@10.33.2` → 10.34.8. Our 11.22+ pins are fine.
8. **Mac:** Node 24.18.0 → **24.22.1** (Brotli RCE), Bun 1.4.2 → 1.4.4, Tailscale 1.102.3 →
   1.104.2, Codex 0.146.0 → 0.164.0, cloudflared 2023.1.0 → 2026.10.3, OrbStack 2.2.5.
9. **VPS, with the user's OK:** Tailscale 1.104.1 → 1.104.2, docker-ce 29.9.1 → 29.9.2,
   holapy-nav's `nginx:1.29-alpine` → `1.30-alpine` (1.29 gets no fixes and is public on
   rutas.holapy.com), Dokploy v0.30.8 → v0.30.10.
10. **Flutter 3.47.8 / Dart 3.13.7** (Android TLS MITM via eMudhra): pasapy's `.fvmrc` 3.47.7 →
    3.47.8; jajotopa and rogapy build with whatever is installed. App builds needed to reach phones.
11. **Lockfile IOC check.** Run on 2026-10-25 against every repo with both IOC lists: **no hits**. No ChainDrop files or injected hooks found, and
    `~/.config/gh-token-monitor` does not exist on the Mac.

Already fine: VPS Ubuntu packages (kernel 6.8.0-147, OpenSSL 3ubuntu3.16, ca-certificates and
NSS from Oct 20–21, OpenSSH 13.20 — unattended-upgrades did it ✓), pgvector 0.8.7 in both
